# Imagens dos exercícios — V5

Esta versão substitui o player de vídeo por imagens individuais em três etapas:
**Posição inicial → Movimento → Posição final**.

- 12 exercícios de academia
- 9 exercícios em casa
- 21 imagens WebP individuais
- Imagens ampliadas em 2× com reamostragem Lanczos e nitidez leve
- Cada slug do site aponta para sua própria imagem

O treino em casa foi ajustado para corresponder exatamente às demonstrações disponíveis nesta versão.
